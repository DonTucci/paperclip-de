# Paperclip auf Deutsch – de-v2026.916.2

Diese Patch-Version enthält den kleinen Windows-Installer als EXE. Die Weitergabe von Installationsparametern mit Windows-Pfaden und Leerzeichen ist korrigiert.

Voraussetzungen:

- Windows 10 oder neuer
- Git
- Node.js 24.11 oder neuer

Die EXE lädt den Branch `fork/deutsch` aus diesem Fork nach `%LOCALAPPDATA%\Paperclip-DE`. Der PowerShell-Installer bleibt als alternatives Release-Asset verfügbar.
