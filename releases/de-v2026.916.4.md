# Paperclip auf Deutsch – de-v2026.916.4

Diese Version verbessert die Erstinstallation unter Windows:

- Git und Node.js werden auch an den üblichen Installationsorten erkannt, wenn sie nicht im PATH stehen.
- Fehlende Voraussetzungen werden mit getrennten Installationslinks angezeigt.
- Die Ausgabe wird als UTF-8 dargestellt, damit Umlaute korrekt erscheinen.
- Fortschritt, Erfolg und Fehler bleiben im Installerfenster sichtbar.
