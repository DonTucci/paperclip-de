# Paperclip auf Deutsch – de-v2026.916.1

Diese Version enthält einen kleinen Windows-Installer als EXE. Die EXE enthält die geprüfte Installationsroutine, startet sie mit Windows PowerShell und gibt deren Ergebnis zurück.

Voraussetzungen:

- Windows 10 oder neuer
- Git
- Node.js 24.11 oder neuer

Die EXE lädt den Branch `fork/deutsch` aus diesem Fork nach `%LOCALAPPDATA%\Paperclip-DE`. Für die Abhängigkeiten wird beim ersten Lauf `pnpm` über Corepack eingerichtet.

Der PowerShell-Installer bleibt als alternatives Release-Asset verfügbar.
